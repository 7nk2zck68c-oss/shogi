# 将棋・内蔵AI強化版

Scratchで動く、1人対コンピューター用の将棋プロジェクトです。外部APIやCloudflare Workerを設定しなくても対戦できます。

## AIの内容

- 盤上移動と持ち駒打ちを含む合法候補を毎手生成
- 先手の全駒の利きを調べ、狙われている後手駒と攻撃元を検出
- 「逃げる」「攻撃駒を取る」「相手駒を取る」「危険な升目を避ける」を駒価値付きで比較
- 成り、中央、前進を評価
- 序盤12手までは14個の囲い・駒組み候補を加点
- 移動元と移動先を盤内81マスで検査し、盤外移動を防止

これはブラウザー内で学習を続ける機械学習モデルではありません。将棋の知識を、定跡表と局面評価ルールとしてScratch内に組み込んでいます。そのため通信不要で誰でも同じAIを使えます。

## Scratchで動かす

1. `project.sb3` をダウンロードします。
2. Scratchの「ファイル」→「コンピューターから読み込む」で選択します。
3. 緑の旗を押します。

標準Scratch命令だけで構成しているため、ChatGPT拡張機能やAPIキーは不要です。

## GitHub Pagesで公開する

1. このフォルダー内のファイルをGitHubリポジトリのルートへアップロードします。
2. GitHubの **Settings → Pages** を開きます。
3. **Deploy from a branch**、公開ブランチの `/ (root)` を選んで保存します。
4. 発行されたURLの `index.html` を開きます。

`index.html` は同じ場所の `project.sb3` をTurboWarpプレーヤーへ渡します。APIキーやWorker URLを入力する欄はありません。

## ファイル構成

- `index.html` — GitHub Pages用の起動画面
- `project.sb3` — Scratch/TurboWarpへ直接読み込める完成版
- `scratch-src/project.json` — Scratchプログラム本体の可読ソース
- `scratch-src/*.svg`, `scratch-src/*.wav` — コスチュームと音声

## 現在の範囲

AIは1手ごとの評価で選択します。数手先を読む本格的な探索エンジンや継続学習ではありません。二歩、打ち歩詰め、王手放置など将棋固有の全例外を完全に証明するエンジンでもありませんが、従来版より相手の射程・駒の損得・退避と取り返しを明示的に評価します。

ビルド情報: 7ターゲット、2,824ブロック、30 SVG、2 WAV、定跡14手。
